# 용어 사전 (Glossary)

기획 문서는 한국어, 코드는 영어 식별자를 씁니다. 둘이 어긋나면 대화가 어긋납니다.
**새 용어가 등장하면 그 자리에서 여기에 등록합니다.** 등록되지 않은 용어는 문서에 쓰지 않습니다.

출처는 [gdd.md](gdd.md) v0.4입니다. 스크립트명은 gdd 17.3장을 따릅니다.

## 코어 메커닉

| 한국어 | 코드 식별자 | 뜻 |
|---|---|---|
| 넉백 | `Knockback` | 폭발·타격으로 캐릭터가 밀려나는 것. 이 게임의 핵심 메커닉 |
| 폭발 | `Explosion` | 로켓이 터지며 반경 4.5 m 내 대상에게 데미지와 넉백을 주는 사건 |
| 직격 | `DirectHit` | 로켓이 캐릭터에 직접 맞은 경우. 데미지 35 · 넉백 14 m/s |
| 스플래시 | `Splash` | 폭심 거리에 따라 감쇠하는 범위 피해. 근접일수록 넉백이 크다 |
| 낙사 | `RingOut` | 맵 밖으로 밀려나 `Y < -20` 를 넘어 탈락하는 것. **주 처치 수단** |
| 낙사킬 | `RingOutKill` | 낙사로 발생한 처치. 결과 화면에 별도 집계한다 |
| 킬 크레딧 | `KillCredit` | 처치를 누구의 공로로 볼 것인가. 낙사는 최근 5초 내 마지막 넉백자 |
| 로켓 점프 | `RocketJump` | 자기 발밑에 로켓을 쏴 그 넉백으로 이동하는 기술 |
| 견인 | `Pull` | 갈고리가 대상을 끌어당기는 강제 이동. 넉백과 같은 속도 경로를 쓴다 |
| 킬존 | `KillZone` | `Y = -20` 의 트리거 콜라이더. 진입 시 즉사 |

## 캐릭터 · 클래스

출처는 [worldbuilding.md](worldbuilding.md). 클래스와 캐릭터는 현재 1:1로 대응합니다.

| 한국어 | 코드 식별자 | 뜻 |
|---|---|---|
| 스파크 | `Spark` | 스피드 클래스 캐릭터. 스킬은 대시. 컬러 네온 그린 & 옐로우 |
| 로카 | `Rocca` | 공격 클래스 캐릭터. 스킬은 예비탄. 컬러 핫 오렌지 & 레드 |
| 기즈모 | `Gizmo` | 기술 클래스 캐릭터. 스킬은 갈고리. 컬러 시안 & 다크 퍼플 |
| 스피드 클래스 | `ClassType.Speed` | 회피·기동 특화 |
| 공격 클래스 | `ClassType.Attack` | 마무리 화력 특화 |
| 기술 클래스 | `ClassType.Tech` | 견인·유틸리티 특화 |

## 장비 · 스킬

| 한국어 | 코드 식별자 | 뜻 |
|---|---|---|
| RPG | `Rpg` / `RpgLauncher` | 전원이 들고 시작하는 유일한 기본 무기 |
| 제트팩 | `Jetpack` | 연료 4초의 공중 기동 장치. 피격 시 1초 사용 불가 |
| 대시 | `Dash` | 스피드 클래스 스킬. 6 m 돌진 + 0.2초 강제 이동 50% 저항 |
| 예비탄 | `SpareShot` | 공격 클래스 스킬. 재장전 무시 보조 로켓 1발 |
| 갈고리 | `GrappleHook` | 기술 클래스 스킬. 12 m 견인, 적·아군 구분 없음 |
| 강화 칩 | `UpgradeChip` | RPG 등급(Mk.I~IV)을 올리는 필드 픽업 |
| 특수 탄두 | `Warhead` | 3발 한정 픽업 탄두 (그래비티 / 클러스터 / 바운스 / 스티키) |
| 치료제 총 | `HealGun` | 팀전 전용. 다운된 아군을 조준해 맞히면 구조 |

## 매치 진행

| 한국어 | 코드 식별자 | 뜻 |
|---|---|---|
| 아레나 | `Arena` | 한 판이 벌어지는 전투 공간(씬) |
| 매치 | `Match` | 시작부터 승패 확정까지의 한 판 |
| 축소 | `Collapse` | 정거장 모듈이 분리되어 떨어져 나가며 유효 구역이 줄어드는 것 |
| 페이즈 | `CollapsePhase` | 축소 스케줄의 한 단계. 모드 A는 총 6페이즈 |
| 다운 | `Down` | 팀전에서 HP 0 시 전환되는 20초 구조 대기 상태 |
| 리벤지 연출 | `Revenge` | 사망 시 가해자 표시 + 킬러 시점 추적 카메라 |
| 복수 마커 | `RevengeMarker` | 모드 B에서 리스폰 후 HUD에 표시되는 킬러 방향 화살표 |
| 팀킬 낙사 | `FriendlyRingOut` | 팀전에서 아군을 밀어 낙사시킨 사고. 의도된 코믹 요소로 결과 화면에 별도 표기 |

## 기술 용어

| 한국어 | 코드 식별자 | 뜻 |
|---|---|---|
| 권한 | `Authority` | 어떤 값을 누가 결정하는가. 이 게임은 호스트 권위 |
| 호스트 | `Host` | Fusion 2 Host Mode에서 판정을 담당하는 주체 |
| 지연 보상 | `LagCompensation` | 네트워크 지연을 되감아 판정하는 기법 |
| 오브젝트 풀 | `ObjectPool` | 생성·파괴 대신 재사용하는 인스턴스 저장소 |
| 외부 속도 | `_externalVelocity` | 넉백·견인으로 주어지는, 입력과 무관한 속도 성분 |
| 좌우 제어 | `LateralControl` | 넉백으로 날아가는 중, 날아가는 축의 좌우로만 허용되는 조작 (gdd 23.3) |

## 작성 규칙

- 한 개념에 하나의 한국어 표기, 하나의 코드 식별자. 동의어를 만들지 않습니다.
  (예: "밀려남"과 "넉백", "제트백"과 "제트팩"을 섞어 쓰지 않는다 — **제트팩**이 정식 표기)
- 코드 식별자는 실제로 쓰이는 타입·메서드명과 일치시킵니다. 코드가 바뀌면 이 표도 바꿉니다.
