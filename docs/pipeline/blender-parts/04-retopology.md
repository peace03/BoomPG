# 04. 리토폴로지 — 필요한 곳의 면 구조 정리

[메인 목차](../blender-parts-workflow.md) · 이전: [03. 메시 수정](03-mesh-editing.md) · 다음: [05. 텍스처](05-texturing.md)

## 목적과 입력

03에서 맞춘 겉모양을 유지하며 **변형·표면 표현·게임 예산에 맞는 면 연결**을 만든다.
입력은 형태 보정본, 원본 텍스처, 기존 UV·웨이트·Shape Key 정보, 파츠 분류와 예산이다.

2026-09-18 사용자 합의: **전체를 검사하고 필요한 곳만 정리한다.**
얼굴·관절은 면 흐름, 강체 장비는 형태·면 수를 중심으로 판단한다.
검사 결과가 양호한 부분은 유지한 이유를 기록하고 넘어간다. 리토폴로지 단계가 있다는 이유만으로 전부 새로 만들지 않는다.

## 쉬운 용어

| 용어 | 뜻과 예 |
|---|---|
| 토폴로지 | 점과 선, 면이 연결된 방식. 겉모양이 같아도 연결은 다를 수 있음 |
| 에지 루프 | 이어지는 면 경계선. 눈·입 둘레나 팔꿈치 주변에 흐름을 만듦 |
| 쿼드·트라이·엔곤 | 네 꼭짓점 / 세 꼭짓점 / 다섯 개 이상 꼭짓점을 가진 면 |
| 폴 | 쿼드 면 흐름에서 연결 선이 보통의 4개와 다른 점. 배치에 따라 접힘이나 움푹 패임을 유발할 수 있음 |
| 스냅·Shrinkwrap | 새로 정리한 점을 기준 모델 표면에 붙이는 기능 |
| Decimate·Remesh | 면을 줄이는 기능 / 표면을 샘플링해 면 구조를 다시 만드는 기능 |
| 베이크 | 상세한 표면의 정보나 기존 색을 새 모델용 이미지로 옮기는 작업 |

## 전체 검사와 처리 결정

| 상태 | 처리 | 통과 판단 |
|---|---|---|
| 면 흐름·예산·변형이 이미 양호 | 유지 | 원화 형태, 구조 검사, 적용되는 변형 검사 증거 |
| 일부 긴 면·겹침·관절 루프 부족 | 부분 리토폴로지 | 그 영역과 접합부, 영향받는 변형 재검사 |
| 강체의 평면·완만한 곡면이 과밀 | 선택 영역 Dissolve/Decimate 또는 부분 재배치 | 외곽·모서리·구멍·반사·삼각형 수 비교 |
| 얼굴·몸 전체가 변형에 부적합 | 전체 재구성 후보 보고 | [03의 전체 재구성 확인](03-mesh-editing.md#수정-범위-선택) 후 실행 |

자동 Remesh나 Decimate 결과를 그대로 “애니메이션용 리토폴로지 완료”로 표시하지 않는다.
자동 결과를 시작점으로 쓸 때도 아래의 면 흐름·표면 일치·변형 검사를 통과해야 한다.
매니폴드·자기 교차·퇴화 면 검사는 구조 검사다. 모두 통과해도 움푹 패인 평면이나 찌그러진 원통은 외관 미충족이다.
Shrinkwrap·베이크로 원본 결함을 다시 옮기지 않도록 기준 표면과 전달할 디테일을 확인한다.

## 작업 순서

1. **표면 기준을 고정한다.** 형태 보정본은 읽기 기준으로 보존하고, 그 위에 수정용 메시를 따로 둔다.
   원본 AI 모델의 함몰·찌그러짐이 남은 부위는 합격 표면으로 삼지 않는다. 03에서 먼저 고친다.
2. **변형 범위와 예산을 확인한다.** 몸·얼굴·손의 필요한 동작, 파츠별 예산과 캐릭터 합계 상한을 기록한다.
   파츠 배분이 없으면 임의의 숫자를 만들지 않고 확인한다. 아직 없는 파츠를 합계에서 0으로 처리하지 않는다.
3. **남길 영역을 정한다.** 정상 영역의 UV·웨이트와 연결을 보존하고, 고칠 영역을 그룹으로 특정한다.
4. **큰 흐름부터 배치한다.** 주요 경계·개구부·관절 주변 → 연결부 → 중간 곡면 순서다.
5. **기준 표면에 맞춘다.** 스냅이나 Shrinkwrap을 사용하고, 반대편 표면에 붙거나 틈을 가로질렀는지 확인한다.
6. **면 밀도를 조정한다.** 실루엣·곡률·관절·표정에 필요한 곳에 면을 배분하고 평평한 부분을 줄인다.
7. **연결과 노멀을 정리한다.** 경계 연결, 중복·퇴화, 뒤집힘, 불필요한 내부 면, 의도된 열린 면을 확인한다.
8. **변형 데이터를 처리한다.** 기존 뼈대와 웨이트를 아래 규칙으로 유지·전달하고 대표 포즈를 확인한다.
9. **내보낼 삼각형 분할을 확인한다.** 편집용 쿼드를 보존하되 베이크·내보내기에 쓰는 분할과 노멀 상태를 고정한다.
10. **저장·8방향 검수 후 UV 단계로 인계한다.** 새 표면에 옮겨야 할 색·결·노멀 정보와 원본 경로를 적는다.

## 변형 메시와 강체의 기준

| 대상 | 면 배치 기준 | 확인할 실패 |
|---|---|---|
| 눈·입 | 눈꺼풀·입술 경계를 따라 연결. 표정 범위가 정해지면 닫히고 열릴 공간 확보 | 눈/입이 닫히지 않음, 입꼬리 찢어짐, 안구 관통 |
| 얼굴·광대 | 기준 볼륨을 유지하고 눈·코·입 흐름을 연결. 선이 몰리는 위치를 표정에 맞춰 조정 | 웃거나 눈을 감을 때 광대가 움푹 패임 |
| 어깨·겨드랑이 | 몸통과 팔로 이어지는 흐름, 벌리고 내릴 때의 접힘 여유 | 팔 올릴 때 체적 소실, 겨드랑이 붙음 |
| 팔꿈치·무릎 | 접히는 위치와 주변으로 면을 분산. 필요한 루프 수는 굽힘 결과로 결정 | 한 줄에 접힘 집중, 껍질 찢어짐·관통 |
| 손·손가락 | 엄지 방향과 손가락 분리, 관절 둘레와 손바닥 연결 | 주먹·무기 잡기에서 겹침, 손가락 뿌리 붕괴 |
| 고글·장비 | 외곽 곡률·두께·구멍·하드 에지를 유지. 평평한 면은 단순화 | 원형 입구가 각짐, 두께 소실, 반사에 울퉁불퉁한 얼룩 |
| 패널·프레임 | 평면·모서리·단차를 유지하고 구멍 주변에 필요한 면 배치 | 삼각형 분할 뒤 핀칭, 브래킷 구멍 소실 |
| 노즐·원통 | 둘레와 길이 방향의 곡률에 따라 면 배분 | 단면 각짐, 축 방향 울렁임, 내벽과 외벽 교차 |
| 가동 장비·연결부 | 분리 경계·회전축·슬라이드 공간 보존 | 부품끼리 용접됨, 가동 중 틈 폐쇄·관통 |
| 머리카락 강체 | 큰 가닥의 곡률·끝·빈 공간 우선, 미세 결은 맵으로 표현 | 가닥 끝이 사라짐, 뒤쪽 볼륨이 줄어듦 |

- 변형 부분은 읽기 쉬운 쿼드 흐름을 우선하되 **모든 면을 쿼드로 만드는 것 자체를 합격 조건으로 삼지 않는다.**
- 강체의 삼각형은 허용한다. 비평면 엔곤·길고 가는 면은 삼각형 분할 후 셰이딩을 확인한다.
- 면을 줄였어도 실제 게임 정점 수는 UV·노멀 경계에서 늘 수 있다. Blender 정점 수만으로 성능을 확정하지 않는다.
- 원래 의도된 비대칭과 두께를 유지한다. Shrinkwrap이 잘못된 표면에 붙으면 대상 영역·거리·방향을 제한한다.

## 웨이트와 변형 확인

이 절은 실제로 휘는 대상에 적용한다. 고정 장비는 웨이트 검사를 `해당 없음`으로 적고 외관·부착·간섭을 검사한다.
회전·슬라이드 장비는 합의한 축·피벗과 대표 위치를 검사하며 가동 경계를 용접해 합치지 않는다.
혼합 모델은 부품별로 검사한다. 예: 제트팩 본체는 곡면·부착, 움직이는 호스는 굽힘·접속부를 확인한다.

1. 기존 Armature·휴식 포즈·본 이름을 먼저 보존한다. 메시를 바꿨다는 이유로 뼈대를 새로 만들지 않는다.
2. 정점 연결이 바뀌지 않은 영역은 기존 웨이트 유지 여부를 확인한다.
3. 새로 만든 영역은 원본과 위치를 맞춘 뒤 Data Transfer 등으로 웨이트 전달 후보를 만든다.
   자동 전달은 결과 검증을 대신하지 않는다. 인접한 다른 손가락·반대쪽 팔의 웨이트가 넘어오지 않았는지 본다.
4. Shape Key는 정점 수·순서에 의존한다. 재구성 후 그대로 유지된다고 가정하지 않고 보존·재작성 범위를 확인한다.
5. 몸은 팔 올리기·팔꿈치/무릎 굽히기·몸통 비틀기, 손은 주먹/무기 잡기,
   얼굴은 합의된 눈 감기/입 벌리기 등의 대표 포즈를 확인한다. 각도·포즈 이름과 결과 이미지를 남긴다.
6. 실패 원인이 면 흐름인지 웨이트인지 구별한다. 면을 늘리기 전에 웨이트 분포도 확인한다.
7. 리그가 없어서 실제 변형 검사를 못 했다면 `리토폴로지 구조 확인 / 변형 미확인`으로 보고한다.
   이 상태를 “애니메이션 검증 완료”로 바꾸지 않는다. 정식 리깅 범위는 별도로 확인한다.

## 합격 기준과 인계

- [ ] 유지·부분 정리·전체 재구성의 선택 이유와 범위가 기록됐다.
- [ ] 원화 대응 외곽·랜드마크·두께를 보정본과 비교했고, 합의한 오차 안이다.
- [ ] 관절·표정 루프 또는 강체의 외곽·곡면을 해당 분류 기준으로 확인했다.
- [ ] 의도하지 않은 메시 결함이 없고, 삼각형 분할 후 표면도 확인했다.
- [ ] 대상 예산과 캐릭터 합계를 확인했거나, 조립 전이라 합계 미확인임을 명시했다.
- [ ] 기존 변형 데이터의 영향과 실제 포즈 검사 결과가 구별되어 있다.
- [ ] 최종 수정 이후 8방향을 확인했고, 베이크 원본과 작업용 저밀도 메시를 구별했다.

형태가 변했으면 03, 면 흐름이 실패하면 04, 색이 틀어졌으면 UV 상태를 포함해 05로 인계한다.
정해진 횟수나 임의의 사각형 비율만 채우고 종료하지 않는다.

## 토큰·재작업 절약

- 처음부터 전체 메시를 새로 짜지 않는다. 점검표에서 문제로 확인된 영역을 우선한다.
- 얼굴·관절·평면 장비를 같은 자동 설정으로 반복 처리하지 않는다. 분류별 실패 원인에 맞는 기능을 쓴다.
- 변형 검사를 UV·최종 베이크 전에 수행해 다시 펼치고 다시 굽는 비용을 줄인다.
- 면수·표면 거리·결함 수는 로컬 계산으로 요약한다. 자동 표면 거리만으로 얇은 부분 소실이나 실루엣을 통과시키지 않는다.
- 도구 출력은 `수정 영역 / 전후 tris / 표면 비교 / 포즈 결과 / 남은 UV·웨이트 작업`만 전달한다.

## 조사 근거

확인일: 2026-09-18. 부위별 검수·실패 분류는 공식 도구 원리와 프로젝트 애니메이션 요구를 종합한 절차다.

- [Blender 5.2 — Remeshing / Retopology](https://docs.blender.org/manual/id/5.2/modeling/meshes/retopology.html): 자동 재생성과 변형용 면 흐름의 차이, 표면 기준을 따르는 수동 정리.
- [Blender — Poly Build](https://docs.blender.org/manual/en/4.5/modeling/meshes/tools/poly_build.html): 국소 면 추가·삭제·이동·돌출 도구.
- [Blender Studio — Reprojection](https://studio.blender.org/training/realistic-human-research/reprojection-sculpt-layers/): 잘못된 표면 투영 때 범위 제한·정점 위치 조정. 여기서는 유료 애드온이나 전체 강좌 절차를 필수로 도입하지 않는다.
- [Blender 5.2 — Data Transfer](https://docs.blender.org/manual/ja/5.2/modeling/modifiers/modify/data_transfer.html): UV·노멀·버텍스 그룹 등 데이터의 대응 관계와 전달.
- [Unity 6 — 모델 최적화](https://docs.unity3d.com/6000.0/Documentation/Manual/ModelingOptimizedCharacters.html): 품질과 폴리곤·재질·변형 비용을 함께 판단하는 원칙.
