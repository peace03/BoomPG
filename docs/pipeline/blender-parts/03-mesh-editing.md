# 03. 메시 수정 — 기존 형태를 살려 보정

[메인 목차](../blender-parts-workflow.md) · 이전: [02. 반입 점검](02-intake.md) · 다음: [04. 리토폴로지](04-retopology.md)

## 목적과 입력

AI 모델의 외곽·표면·두께·개구부·연결부 등 잘못 만들어진 **겉모양**을 원화에 맞춘다.
신체의 눈·손, 장비의 패널·노즐·프레임 모두 같은 원인 진단과 전후 판정을 적용한다.
입력은 보존된 원본, 수정용 `.blend`, 분석표, 반입 점검 결과다.
이 단계가 끝나면 형태를 기준으로 삼을 모델을 저장한다. 면의 연결 구조는 다음 단계에서 별도로 판단한다.

## 쉬운 용어

| 용어 | 뜻과 용도 |
|---|---|
| 정점 이동 | 표면의 점 위치를 옮겨 모양 수정 |
| 비례 편집 | 선택한 점 주변도 부드럽게 따라 움직임. 외장 곡면·신체 볼륨처럼 넓은 보정에 사용 |
| 스컬핑 | 점토를 밀고 깎듯 브러시로 표면 수정 |
| 마스크·버텍스 그룹 | 건드릴 곳과 보호할 곳을 구별하는 표시 |
| 베벨·Solidify | 모서리 라운딩 / 얇은 면에 실제 두께 추가 |
| 모디파이어 | 원본 메시 위에 쌓는 수정 효과. 적용 전에는 설정을 되돌릴 수 있음 |
| 노멀·셰이딩 | 표면 방향 / 그 방향과 재질·조명으로 계산한 명암 |

## 수정 범위 선택

2026-09-18 사용자 합의: **기존 메시 우선, 부분 재구성 허용, 전체 재구성은 설명 후 확인받기.**

`기존 메시 유지`는 원본의 결함까지 유지하거나 정점 이동을 약하게만 하라는 뜻이 아니다.
승인된 형태 보정 안에서 정점 재배치·국소 면 재연결·부분 재구성으로 결함을 실제로 해결한다.
합의한 특징·치수·예산을 지키며, 이미 승인된 통상 보정을 다시 묻지 않는다.

| 관찰된 문제 | 먼저 할 작업 | 다음 선택의 조건 |
|---|---|---|
| 형태만 부풀거나 비틀림 | 기존 정점 이동·비례 편집·마스크 스컬핑 | 면이 심하게 늘어나거나 접히면 해당 부분 연결 구조 정리 |
| 손가락·끈·프레임 일부가 붙음 | 해당 부분 분리·국소 면 삭제/재생성·경계 연결 | 주변까지 오류가 이어지면 수정 범위를 넓히는 이유 기록 |
| 넓은 영역이 구조적으로 붕괴 | 남길 수 있는 부위와 수정 비용을 먼저 비교 | 전체 재구성 후보를 제시하고 사용자 답변 대기 |
| 전체 형상보다 재질이 이상함 | 단색 뷰·노멀·조명으로 원인 분리 | 형태가 정상이라면 메시를 바꾸지 않고 05로 인계 |

전체 재구성 질문에는 **문제 이미지, 기존 메시로 해결하기 어려운 이유, 유지할 특징,
바뀔 외곽과 두께, UV·웨이트·텍스처 영향, 부분 수정 대안**을 포함한다.
부위들을 차례로 다시 만들어 사실상 전체를 교체하는 방식으로 확인 절차를 피하지 않는다.
이미 해당 범위의 재구성이 승인됐다면 같은 질문을 반복하지 않는다. 답변 대기에는 시간제한이 없다.

## 작업 순서

1. **수정 묶음을 정한다.** 예: “광대와 눈 주변 비율” 또는 “좌우 노즐 입구”. 대상 ID·유지할 부분을 기록한다.
2. **형태와 명암 오류를 구분한다.** 원화 시점, 단색 형태, 와이어프레임, 재질 뷰를 비교한다.
3. **기존 메시를 보호한다.** 수정본에서 대상 영역을 마스크/그룹으로 한정한다. 반대편·인접 부품을 숨기거나 보호한다.
4. **큰 형태부터 조정한다.** 전체 비율 → 국소 높이·폭·깊이 → 재료 두께·빈 공간 → 세부 순서다.
5. **국소 작업을 선택한다.** 아래 부위별 규칙을 적용한다. 자동 기능은 작은 선택 영역에서 결과를 확인한 뒤 넓힌다.
6. **접합과 표면을 정리한다.** 경계 연결·의도하지 않은 겹침·퇴화 면·노멀을 점검한다.
7. **기존 데이터를 확인한다.** UV 늘어짐, 웨이트, Shape Key, 모디파이어에 끼친 영향을 기록한다.
8. **저장 후 8방향을 확인한다.** [06. 검수](06-review.md)로 이동해 이 묶음의 변경과 다른 부위의 악화를 확인한다.
9. 형태 기준을 충족한 모델을 리토폴로지의 표면 기준으로 보존한다. 미충족이면 원인에 해당하는 작업으로 돌아간다.

## 작업을 망치기 쉬운 선택

- 함몰·울렁임은 해당 부위를 특정하고 의도한 평면·곡면·단면으로 복원한다. 전체 Smooth나 약한 평균화만 적용한 것을 해결로 취급하지 않는다.
- Normal 강도·Roughness·조명 조절은 실제 패인 정점을 복구하지 않는다. [02의 원인 분리](02-intake.md#잘못된-판정-방지) 후 원인에 맞게 수정한다.
- 같은 조건의 확대 전후 비교에서 결함이 남으면 `미충족`을 유지하고 선택 범위·목표 표면·면 연결을 재검토한다.
  같은 자동 보정을 효과 없이 반복하지 않는다. 악화되면 직전 상태로 되돌리고 다른 국소 방법을 적용한다.
- 비례 편집은 영향 반경과 `Connected Only`를 확인한다. 손바닥으로 연결된 옆 손가락은 이 설정만으로 보호되지 않으므로 마스크·선택 범위도 제한한다.
- `Smooth`를 반복해 눈꺼풀·모서리·끈을 지우지 않는다. 형태를 만든 뒤 제한적으로 사용한다.
- `Merge by Distance`의 거리는 모델 단위와 유지할 최소 간격을 보고 정한다. 전체 자동 용접으로 손가락·띠를 붙이지 않는다.
- `Fill Holes`는 결함 구멍으로 확인한 영역에만 사용한다. 의도된 입구까지 폐쇄하지 않는다.
- Mirror는 실제 대칭 영역에만 사용한다. 원화의 의도된 비대칭을 없애지 않는다.
- Voxel Remesh·Dyntopo처럼 면 구조를 바꾸는 기능은 UV·웨이트·Shape Key 보존 영향을 먼저 확인한다.
  형태 작업용 복사본과 게임용 원본을 분리하며, 전체 적용은 위 수정 범위 합의를 따른다.
- `Ctrl+J`는 오브젝트를 묶는 기능이다. 연결되지 않은 경계와 내부 겹친 면은 별도로 확인한다.
- 실루엣에 영향을 주는 두께를 Normal로 대신하지 않는다. Normal은 실제 외곽이나 빈 공간을 만들지 않는다.

## 합격 기준과 인계

- [ ] 형태 결함별 단색·재질 뷰의 같은 조건 전후 확대 비교에서 목표 표면이 복원됐다. 단순 정점 이동량을 개선 증거로 쓰지 않았다.
- [ ] 필수 형태 ID의 비율·두께·깊이·빈 공간을 원화 대응 뷰와 측정으로 확인했다.
- [ ] 수정 영역 밖의 형태·색 배치·변형 데이터가 훼손되지 않았거나 영향이 명시됐다.
- [ ] 의도하지 않은 관통·뒤집힌 면·새로운 핀칭이 없다. 의도된 열린 면은 기록했다.
- [ ] 수정 묶음 종료 후 최신 8방향을 실제 확인했다.
- [ ] 리토폴로지가 따라갈 표면 기준과 기존 텍스처 원본을 별도로 보존했다.

실패하면 형태 수정으로 돌아간다. 합격 기준 자체를 낮추거나 전체를 더 촘촘하게 만드는 것으로 통과시키지 않는다.
미완료 UV 복구·웨이트 재검증은 다음 단계의 입력에 적고, 해당 검증이 끝나기 전 최종 완료를 선언하지 않는다.

## 토큰·재작업 절약

- 큰 모양을 확정한 뒤 미세 결을 다룬다. 본체·얼굴 등 기준 표면을 다시 바꿀 때마다 전체 텍스처를 새로 굽는 일을 피한다.
- 변경 대상을 오브젝트 이름·그룹·ID로 유지한다. 매번 전체 씬을 새로 분석하지 않는다.
- 반복 가능한 크기 조절·측정은 검증된 스크립트와 매개변수를 재사용한다. 대상 이름·파일 상태를 실행 전에 확인한다.
- 한 묶음 안의 작은 수정은 해당 부위 확대 뷰로 확인하고, 묶음 종료 시에는 8방향 모두 확인한다.
- 도구 반환값은 `대상 / 변경값 / 전후 치수 / 새 오류 / 저장 경로`로 제한한다. 실행 오류는 원문을 보존한다.

## 국소 보정에 적용할 도구 원리

- 평면 패널은 경계·모서리를 보호하고 목표 평면에 해당하는 정점만 정렬한다. 평탄화 도구의 평면·영향 강도를 확인하며 패널 두께나 옆면까지 같은 평면에 밀어 넣지 않는다.
- 원형 노즐은 중심·반경·축을 정하고 해당 단면을 원형으로 보정한다. 의도된 타원·비대칭에는 강제 적용하지 않는다.
- 설치 버전의 기능·옵션을 먼저 확인한다. 아래 매뉴얼의 메뉴가 없으면 정점 정렬·좌표 조정으로 같은 목표를 구현하며, 미확인 API를 추측하지 않는다.
