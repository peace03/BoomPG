# 01. 원화 분석 — 무엇을 맞출지 정하기

[메인 목차](../blender-parts-workflow.md) · 다음: [02. 반입 점검](02-intake.md)

## 목적과 입력

원화와 사용자 설명을 **수정 전에 확인할 수 있는 합격 기준**으로 바꾼다.
입력은 원화, 파츠 이름, 용도, 사용자가 정한 크기·수정 범위다.
원본 파일은 [02의 폴더 규칙](02-intake.md#폴더와-파일)에 따라 보존한다.

## 쉬운 용어

| 용어 | 뜻과 예 |
|---|---|
| 실루엣 | 검게 칠했을 때 남는 외곽선. 머리 묶음·제트팩 노즐처럼 멀리서도 보이는 모양 |
| 랜드마크 | 비교할 기준점. 눈꼬리, 입꼬리, 고글 위·아래 끝, 노즐 중심 |
| 단면·두께 | 물체를 잘랐다고 생각했을 때의 모양과 재료 두께. 외장 벽·렌즈·피부 등 |
| 단차 | 이웃한 표면의 높이 차이. 프레임보다 안으로 들어간 렌즈 |
| 직교·원근 | 직교는 거리에 따른 크기 변화가 없고, 원근은 가까운 부분이 크게 보이는 투영 |
| 스킨드·강체 | 뼈와 웨이트에 따라 휘는 메시 / 이동·회전해도 자체 형태는 유지하는 부품. 강체가 반드시 본에 붙는 것은 아님 |

## 분석 순서

1. 원화의 파일 경로와 작업 대상, 사용자가 이미 확정한 사항을 기록한다.
2. 여러 원화가 있으면 앞·뒤·옆의 대응을 확인한다. 서로 모순되면 우선할 원화를 묻는다.
3. 아래 표를 파츠에 적용하고 필수 요소에 ID를 붙인다. 관찰 사실, 추정, 사용자 확정을 구분한다.
4. 전체 치수와 국소 치수를 따로 적는다. 원근 그림의 픽셀 길이를 실제 cm로 단정하지 않는다.
5. 불명확한 구조·재질만 공식 제작 자료나 제조사 자료로 보충한다. URL·확인일·적용 이유를 남긴다.
6. 결과를 바꾸는 미확정 사항은 아래 질문 방식으로 확인한다. 답을 기다리는 항목은 `미확인`으로 둔다.
7. `Notes/Analysis_<날짜_시간>.md`를 저장하고 반입 점검으로 넘어간다.

## 분석 항목

| 요소 | 원화에서 찾을 것 | 모델에서 확인할 것 |
|---|---|---|
| 컨셉·정체성 | 기능, 스타일, 강조점, 핵심 색과 형태 | 작은 화면에서 특징이 읽히는가 |
| 실루엣·큰 덩어리 | 외곽선, 볼륨 분포, 곡률, 돌출부 | 앞·뒤·옆에서 큰 비율이 맞는가 |
| 전체 크기·비율 | 폭·높이·깊이, 장착 대상·인접 부품과의 상대 크기 | 단위, 실제 치수, 작업 크기와 조립 크기 |
| 부분 높이·폭 | 렌즈 높이, 프레임 폭, 손가락 굵기 | 정한 지점 사이의 거리·비율 |
| 두께·단면 | 얇은 띠, 속이 빈 부분, 모서리 단면 | 실제 앞뒤 면, 얇은 끝의 소실 |
| 깊이·단차 | 돌출·함몰, 겹치는 순서, 라운딩 | 표면 높이 차이, 프레임 깊이, 렌즈 함몰 |
| 빈 공간·결합 | 노즐 입구, 코 파임, 고리, 연결부 | 막힘·떠 있는 틈·관통·잘못 메워진 공간 |
| 대칭·배치 | 의도된 좌우 차이, 개수·각도·간격 | 중심선, 누락·중복·잘못된 반복 |
| 중간 형태 | 머리 묶음, 주름, 패널 흐름 | 큰 덩어리 안의 형태 연결 |
| 미세 디테일 | 머릿결·끈·재봉선·홈·로고 | 메시·색·Normal 중 어디에 표현할지 |
| 색·패턴 | 주색·보조색·강조색과 면적 | 앞뒤 연속성, 색 경계와 뒤쪽 누락 |
| 재질·표면 | 천·플라스틱·금속·유리의 외관 | 고유색, 거칠기, 금속성, 투명도 |
| 조명·카메라 | 시점·가림·그림자·하이라이트 | 고유색/형태 차이와 촬영 조건 차이를 구별 |
| 구조·변형·가동 | 신체 관절, 끈·호스의 굽힘, 장비의 힌지·회전축 | 해부학 또는 부품 구조의 오류, 접힘·회전·이동 범위와 간섭 |
| 조립·게임 조건 | 부착 위치, 인접 파츠, 보일 거리 | 본·웨이트·간섭·피벗·전체 예산 |
| 가려진 부분 | 원화에 없는 뒤·안·바닥 | 보이는 구조와 연결되는 추정, 확인이 필요한 부분 |

**예: 고글 렌즈 높이, 프레임 폭, 프레임 깊이, 렌즈 함몰, 유리 자체 두께는 각각 측정한다.**
고글 전체를 크게 만드는 것으로 다섯 항목을 동시에 충족했다고 판정하지 않는다.
Spark 고글 폭 20 cm, 공용 제트팩 높이 50 cm는 해당 파츠의 기존 결정이며 다른 파츠의 기본값이 아니다.

## 질문 방식

- 장비는 “고정 모형 / 부품 회전·슬라이드 / 끈·호스 굽힘” 중 실제 사용 방식을 확인한다. 가동 기능이 없는 장비에 리그나 애니메이션을 임의로 추가하지 않는다.
- 기술 용어는 먼저 생활 언어로 설명하고, 선택이 외형·동작·작업량에 주는 차이를 설명한다.
- 이미 답한 크기·수정 범위·스타일은 다시 묻지 않는다.
- 크기가 없으면 “모델의 전체 높이를 몇 cm로 준비할지”를 묻는다.
- 얼굴 변형 범위가 없으면 “표정 고정 / 눈 깜박임·입 벌림 / 말하기·다양한 표정”의 차이를 설명한다.
  아직 결정되지 않은 표정을 임의로 추가하거나, 필요 없다고 간주하지 않는다.
- 게임 화면 거리·확대 화면 유무가 품질 기준에 영향을 주면 사용 예를 설명하고 확인한다.
- **질문에 시간제한을 두지 않는다. 답변이 없으면 추천안을 자동 선택하지 않는다.**
  답에 의존하는 작업만 보류하고 독립적인 파일 점검·자료 조사는 계속한다.

## 기록과 합격 기준

| ID | 요소·필수 여부 | 근거 구분 | 목표·측정 지점·허용 오차 | 현재 상태 | 증거 | 판정 |
|---|---|---|---|---|---|---|
| G01 | 렌즈 높이·필수 | 원화 관찰 | 정면 위·아래 끝의 거리/폭 비율 | 반입 후 측정 | 앞·앞대각 | 미확인 |
| G02 | 프레임 깊이·필수 | 사용자 확정 또는 원화 추정 | 앞·뒤 면 거리 | 반입 후 측정 | 옆·위·단면 | 미확인 |
| J01 | 제트팩 노즐 단면·필수 | 원화 관찰 | 노즐 축·입구 형상·내벽 두께를 각각 확인 | 반입 후 측정 | 아래·옆·단면 | 미확인 |
| E01 | 장비 패널·필수 | 원화 관찰 | 의도한 단차를 유지하며 불필요한 함몰 제거 | 반입 후 진단 | 단색·대각·확대 | 미확인 |
| M01 | 가동 덮개·조건부 | 사용자 확정 | 합의한 개폐 범위에서 본체와 충돌 없음 | 기능 범위 확인 | 닫힘·열림·중간 위치 | 미확인 |

- 수치가 확정되지 않은 스타일은 “두 노즐 내부가 열려 보인다”처럼 눈으로 확인할 특징을 적는다.
- 판정은 `충족 / 미충족 / 미확인 / 해당 없음`이다. 해당 없음에는 이유가 있어야 한다.
- 목표나 허용 오차를 결과에 맞춰 나중에 넓히지 않는다. 원화·용도·사용자 지시가 바뀌어 기준을 변경할 때는 이유와 비교를 제시하고 확인받는다.
- 원화의 핵심 요소를 만들기 어렵다는 이유로 선택 항목으로 낮추지 않는다.
- 분석 단계의 완료는 **수정할 기준이 준비된 상태**다. 모델이 이미 합격했다는 의미가 아니다.
- 사용자 지적과 반입 점검에서 발견한 함몰·울렁임·왜곡된 무늬도 관련 분석 ID 아래 개별 문제로 등록한다.
  `표면 개선`처럼 넓게 쓰지 않고 `왼쪽 추진기 외벽의 의도하지 않은 함몰 제거`처럼 위치와 해결 모습을 적는다.
  원화의 의도된 홈·사용감과 생성 오류를 구별하고, 원인이 미정이면 진단 대상으로 남긴다.

## 토큰·재작업 절약

- 원화 전체 설명을 매 단계 다시 쓰지 않고 요소 ID와 해당 이미지 경로를 전달한다.
- 확인된 구조는 재검색하지 않는다. 새로운 의문, 도구 버전 변화, 자료 충돌이 있을 때만 추가 조사한다.
- 변경 부위의 비교 기준을 먼저 정해 의미 없는 세부 수정과 재베이크를 줄인다.
- 이미지가 작아 기준을 판단할 수 없으면 확대한다. 불명확한 내용을 짧게 추측해 비용을 줄이지 않는다.

## 조사 근거

확인일: 2026-09-18. 관찰·측정 원리는 아래 자료, 승인·판정 방식은 사용자 합의와 프로젝트 운영 규칙이다.

- [Blender 5.2 — Measure](https://docs.blender.org/manual/de/latest/editors/3dview/toolbar/measure.html): 거리·각도·면 사이 두께의 측정. 곡면의 두께는 표면 위치·방향을 지정해 측정한다.
- [Blender 5.2 — Cameras](https://docs.blender.org/manual/id/5.2/render/cameras.html): 직교와 원근의 크기 표현 차이.
- [Blender Studio — Creature Factory 2](https://studio.blender.org/training/creature-factory-2/): 공개 목차에서 형태 제작·리토폴로지·UV·베이크·리깅 검증의 분리를 확인했다. 유료 강의 본문을 열람한 것으로 간주하지 않는다.
