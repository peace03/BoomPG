# ADR-0006: 캐릭터 실루엣을 스킨 불변 요소로 고정한다

- 상태: 채택
- 날짜: 2026-09-16
- 결정자: YunPyeongHwa
- 근거 문서: [design/worldbuilding.md](../design/worldbuilding.md) 3장,
  [design/gdd.md](../design/gdd.md) 5.2·13장

## 맥락

세계관 문서가 캐릭터 3인을 정의하면서 구분 수단을 **컬러 테마로만** 제시했다
(네온 그린 / 핫 오렌지 / 시안). 그런데 이 게임에는 색만으로 부족한 이유가 세 가지 있다.

1. **카운터 삼각관계가 즉시 판별을 요구한다.** 스파크 → 로카 → 기즈모 → 스파크로 물리는
   구조(gdd 5.2)에서, 상대가 어느 클래스인지 모르면 대응 자체가 불가능하다.
   교전 거리는 로켓 탄속 28 m/s와 폭발 반경 4.5 m를 감안하면 20~40 m 대다.
2. **색은 묻힌다.** 구름 위 밝은 배경, 폭발 섬광, 카툰 렌더링의 높은 채도가 겹치면
   거리에 따라 색상 구분이 무너진다. 3인칭 시점에서 캐릭터가 화면에서 차지하는 픽셀도 작다.
3. **코스메틱이 BM의 축이다** (gdd 13장). 스킨이 계속 추가되는데 색으로만 구분하면
   스킨이 늘어날수록 구분이 어려워진다. gdd 13장도 "실루엣이 배경에 묻히는 스킨"을
   이미 금지하고 있으나, 무엇을 지켜야 하는지가 정의되어 있지 않았다.

## 검토한 선택지

| 선택지 | 장점 | 대가 |
|---|---|---|
| 색으로만 구분 (현행) | 스킨 제작 자유도 최대 | 거리·조명에서 판별 실패. 스킨이 늘수록 악화 |
| **실루엣을 불변 요소로 고정 (채택)** | 색과 무관하게 판별 가능. 스킨이 늘어도 유지됨 | 스킨 디자인에 제약. 모델링 규격을 먼저 정해야 함 |
| UI 마커로 표시 | 확실함 | 화면이 지저분해지고 "죽어도 웃긴" 캐주얼 톤을 해침. 관전·방송 화면에서도 어색 |

## 결정

**세 캐릭터의 실루엣 특징을 스킨이 바꿀 수 없는 불변 요소로 고정한다.**

| 캐릭터 | 불변 실루엣 요소 |
|---|---|
| 스파크 (`Spark`) | 날렵한 역삼각 상체. 좁은 허리. 관절부(어깨·무릎)의 추진기 돌출 |
| 로카 (`Rocca`) | 벌크업된 상체와 넓은 어깨. 가슴을 가로지르는 두꺼운 탄띠 |
| 기즈모 (`Gizmo`) | **좌우 비대칭** — 오른팔 전체를 덮는 과장된 건틀릿 |

**스킨이 바꿀 수 있는 것**: 색, 텍스처, 패턴, 재질, 실루엣을 건드리지 않는 소품
**스킨이 바꿀 수 없는 것**: 전체 비율, 어깨 폭, 위 표의 돌출 요소

## 이유

세 캐릭터의 실루엣 재료가 이미 세계관 문서 안에 있었다. 날렵함 / 벌크업 / 비대칭은
서로 혼동될 여지가 거의 없는 세 가지 형태이고, 각각 클래스의 성격(회피 / 화력 / 유틸리티)과도
자연스럽게 맞물린다. 새로 만드는 제약이 아니라 **이미 있는 설정을 규칙으로 승격**하는 것이다.

UI 마커는 확실하지만 화면을 지저분하게 만들고, 관전 카메라와 리벤지 연출(gdd 15장)처럼
"보는 재미"를 노린 장치들과 충돌한다. 형태로 푸는 편이 이 게임의 톤에 맞다.

## 결과

- **열리는 것**: 색맹 접근성이 덤으로 확보된다. 스킨을 자유롭게 추가해도 판별이 유지된다.
- **닫히는 것**: 캐릭터 실루엣을 크게 바꾸는 스킨(예: 로카를 날씬하게 만드는 스킨)은 만들 수 없다.
- **새로 생기는 작업**:
  - 3D 모델 규격에 불변 요소를 명시하고, 검수 절차에 **실루엣 테스트**를 넣는다
    ([pipeline/asset-pipeline.md](../pipeline/asset-pipeline.md))
  - 코스메틱 제작 가이드라인에 "실루엣 변경 금지"를 넣는다 (M4 이후)
- **영향받는 문서**: `design/worldbuilding.md`, `pipeline/asset-pipeline.md`
- **되돌리는 비용**: 높음. 모델을 만든 뒤 뒤집으면 3종 전부 재작업이고,
  이미 판매한 스킨이 있으면 되돌릴 수 없다. **그래서 첫 캐릭터를 생성하기 전에 정했다.**

## 검증 방법

VARCO 3D로 캐릭터를 생성한 뒤 **실루엣 테스트**를 통과해야 반입한다.

1. 세 캐릭터를 단색(검정)으로 렌더한다
2. 정면·측면·후면 세 각도에서 비교한다
3. 색 정보 없이 **어느 캐릭터인지 즉시 구분되면 통과**
4. 30 m 거리(교전 거리 하한)에서 화면에 보이는 크기로 축소해도 구분되어야 한다

통과하지 못하면 형태를 수정한다. 색으로 보완하지 않는다.
